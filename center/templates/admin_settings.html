Graylog

Graylog только принимает логи, центр в нём только читает: показывает лог fail2ban хоста на вкладке «Лог» (режим «через Graylog» выше). Банят по-прежнему джейлы fail2ban на хостах. Ставить на серверы ничего не нужно. Что сделать в Graylog:

  1. Лог fail2ban хостов (/var/log/fail2ban.log или journald) уже должен приходить в Graylog — rsyslog, Graylog Sidecar, чем угодно. Поле source сообщения — имя хоста; оно сопоставляется с именем агента (или с «Именем хоста в Graylog» в настройках агента). Ниже укажите, как в Graylog отличить эти сообщения от остальных.
  2. System → Users → Create user: роль Reader. Роль сама по себе не даёт искать — дайте пользователю доступ на чтение к потоку с логами (Streams → у потока «Share» → пользователь, «Viewer»), в том числе если это «All messages».
  3. У этого пользователя: Edit tokens → Create token. Токен вставьте ниже.
