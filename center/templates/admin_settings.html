Graylog — настройка подключения (нужна только для режима «через Graylog»)

На стороне Graylog: создайте вход (Input) типа GELF TCP (System → Inputs), с use_null_delimiter=true, и убедитесь, что порт проброшен как TCP (не UDP). Создайте отдельного пользователя с ролью Admin (не встроенный root/admin — у него в некоторых версиях Graylog не работает выпуск персональных токенов) и выпустите ему Personal Access Token (System → Users → ваш пользователь → Tokens). На каждом управляемом хосте нужен свой форвардер, шлющий строки лога fail2ban в этот вход по GELF TCP с полем host = имени агента (для сопоставления с graylog_source, см. ниже) — простой пример скрипта есть в docs/ проекта.
